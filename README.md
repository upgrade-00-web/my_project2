Task Manager



Простое desktop-приложение для управления задачами, написанное на Python с использованием библиотеки Tkinter.



Функциональность

\- Добавление задач с названием, описанием и датой выполнения.

\- Удаление выбранной задачи из списка.

\- Автоматическое сохранение и загрузка задач из файла `tasks.json`.





Запуск приложения

1\. Клонируйте репозиторий или скачайте исходный код.

2\. Запустите файл `gui.py`:

&#x20;  python gui.py
